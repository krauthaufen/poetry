# Open guesses

Generated by `tools/rules/guesses.py` from RULES.md and `src/PoEtry/Constants.fs`. Do not edit.

What the simulator assumes without a source in the game data, the wiki or an in-game
observation. Each wants an in-game test or a data source; when one is found, change the
confidence in RULES.md (and the comment in Constants.fs) and add a test.

## Checking against a new game version

1. Update the game, then `cd tools/gamefiles && npx pathofexile-dat` (tables) and
   `tools/export/export.lua` (data/game).
2. `dotnet run -c Release --project tests/PoEtry.Tests`: the data tests name every gem
   value that moved.
3. `dotnet fsi tools/census/census.fsx` and `tools/skills/ledger.fsx`: new stats and skill
   types nothing reads yet.
4. `dotnet fsi --optimize+ tools/skills/dossier.fsx`, then diff `dossiers.txt`: skills
   whose description or behaviour changed.
5. Go through the lists below; the wiki's version history of a skill says what changed.
